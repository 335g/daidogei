# 大道芸ワールドカップin静岡 2026 スケジュール（駿府城公園エリア）

6歳児連れで駿府城公園エリアを回るための、自分用スケジュールアプリ。静的サイト。10/31〜11/3の4日ぶん。

https://335g.github.io/daidogei2026/

## 何ができるか

見たい演目を1本固定すると、その前後で「時間的に間に合う演目」だけに絞られる。固定を増やすほど候補が減る。移動の目安つきで、間に合わない組み合わせは赤字で警告する。

- **決める** 固定した演目のタイムラインと、その前後に入る候補。「いま」ボタンで現在時刻から2時間ぶんの候補を出す（直前につけた演目の会場を起点にする）
- **探す** 時間枠から / アーティストから、見たい1本を探す
- **時間表** 会場ごとの全演目。★3だけに絞れる
- **プラン** 11/1用のプリセット3案。丸ごとルートに取り込める
- **地図** 会場番号つきのエリアマップと子連れメモ

演目をタップすると、写真・紹介文・その日の出番が出る。

## データ

`data.js` は次の2つから生成した。

- 演技日程: `schedule2026_1014.pdf` の1〜4ページ（DAY1=10/31、DAY2=11/1、DAY3=11/2、DAY4=11/3）
- アーティスト: https://daidogei.com/artist2026/
- プレミアムステージ（有料）の演目: https://daidogei.com/stage/

演目は各30分。会場は31か所（うち6はブース、8は有料）。★は6〜7歳目線の主観評価で、3が鉄板、2が面白い、1が静かめ、評価していないものは星なし。

移動の目安はすべて固定値。園内4分、歴博エリア内2分、市街地5分、園内と市街地の間15分、駅周辺まで20分。駿河区（29）と清水区（30-31）は徒歩圏外として電車・バス扱い（駅から25分／55分）にし、候補には出さない。

## 手元で動かす

```
python3 -m http.server 8000
```

ビルド不要。Service Worker は通信優先なので、更新は普通にリロードすれば反映される。画面下部の「表示バージョン」で確認できる。

## 注意

出演者・時間は変更される場合がある。現地の掲示を優先すること。
