# 大道芸ワールドカップin静岡 2026 / 11月1日(日) 駿府城公園 キッズ攻略

6歳児連れで駿府城公園エリアを回るための、自分用スケジュールアプリ。静的サイト。

https://335g.github.io/daidogei2026/

## 何ができるか

見たい演目を1本固定すると、その前後で「時間的に間に合う演目」だけに絞られる。固定を増やすほど候補が減る。移動は徒歩の目安つき、間に合わない組み合わせは赤字で警告する。

- **決める** 固定した演目のタイムラインと、その前後に入る候補
- **探す** 時間枠から / アーティストから、見たい1本を探す
- **時間表** 会場ごとの全72演目。★3だけに絞れる
- **3案** ゼロから組むのが面倒なとき用のプリセット。丸ごと取り込める
- **地図** 会場番号つきのエリアマップと子連れメモ

## データ

`data.js` は次の2つから生成した。

- 演技日程: `schedule2026_1014.pdf` の2ページ目（11月1日 DAY2）
- アーティスト: https://daidogei.com/artist2026/

演目は各30分。会場は12か所（うち6は演目なしのブース、8は有料のプレミアムステージ）。★は6〜7歳目線の主観評価で、3が鉄板、2が面白い、1が静かめ。

徒歩の目安は園内4分・歴博エリア内2分・園内と歴博の間10分・中央体育館12分の固定値。実際の混雑は考慮していない。

## 手元で動かす

```
python3 -m http.server 8000
```

`index.html` はビルド不要。`data.js` を書き換えたら `sw.js` の `CACHE` の版を上げる（キャッシュが優先されるため）。

## 注意

出演者・時間は変更される場合がある。現地の掲示を優先すること。
