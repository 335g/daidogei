# 来年（次の開催年）の更新手順

このアプリは静的サイトで、**年の情報は `data.js` の中だけ**に入っています。`index.html` と `sw.js` は年を知りません。なので毎年やることは「データの作り直し」だけで、アプリ本体は触りません。

## 用意するもの

| 何 | 例（2026年） | 使い道 |
| --- | --- | --- |
| 演技日程PDF | `schedule2026_1014.pdf` | 全演目の時刻と会場。1ページ＝1日 |
| アーティストページ | https://daidogei.com/artist2026/ | 名前・国・ジャンル・写真・紹介文・出演者番号 |
| エリアマップPDF | `guidemap2026.pdf` | 会場番号つき地図画像の元 |
| プレミアムステージのページ | https://daidogei.com/stage/ | **有料ステージの演目は日程PDFに載っていない**ので、ここから手で入れる |

PDFは `data/` に置く（`data/` は `.gitignore` 済みでリポジトリには入らない）。

## 手順

1. 新しいPDFを `data/` に置く
2. 依存を入れる: `npm install`
3. 抽出する: `node tools/extract-schedule.mjs data/schedule20XX_XXXX.pdf > /tmp/days.json`
   - 標準エラーに `page N: 190 演目` と、要確認の行が出る
4. **`!!` の行を潰す**。WS系の会場（7・15・16・17・21列）は1つのセルに2名ぶんの番号が並ぶことがあり、片方の時刻が15分ずれます。PDFを見て `/tmp/days.json` を直接直す
5. 会場の増減を `data.js` の `stages` に反映する。**`id` はPDFの列番号（1〜31）と一致させる**
6. `data.js` の `artists` を作り直す。名前・国・ジャンル・写真・紹介文は公式ページから。**`kid`（★）と `why`（ひとこと）は前年の `artists` を名前で引き継ぐ**（出演者番号は毎年振り直されるので番号では引き継げない）
7. `data.js` の `premium` に有料ステージの演目を日ごとに手で入れる
8. 必要なら `data.js` の `plans` を作り直す（いまは11/1用の3案だけ）
9. `data.js` の `festival` を新しい年・URLに更新する
10. `sw.js` の `CACHE` の版を上げ、`index.html` の `VER` も上げてpush

## 抽出の仕組み

`tools/extract-schedule.mjs` は、PDFの文字を座標つきで取り出して、次の前提で組み立てています。

- 1ページ＝1日。左から31列が会場（`COL_BOUNDS`）。上から下へ15分刻み
- 各セルは原則30分。セルの中に「出演者番号（2桁）＋名前」が縦積みで入る
- セルの開始時刻は、**文字ブロックの中心から**求めている（ブロックは行数によらず中央寄せされるため）。`CENTER_TO_TOP` はその補正値
- 時刻の目盛りは左端のラベルから作る。ラベルが想定位置から4px以上ずれたら**エラーで止まる**
- 列6（芝生広場）は演目なしのブース、列8（プレミアムステージ）は別ソースなので飛ばす
- 番号 `00` は時刻の断片なので拾わない

レイアウトが変わったときに直すのは `COL_BOUNDS`・`CALIB`・`CENTER_TO_TOP` の3つだけです。

## 出力の検算

2026年版で、このスクリプトの出力と公開中の `data.js` が**全692演目で完全一致**することを確認済みです。作り直したあとは次を見てください。

- 各日の演目数: 2026年は 190 / 192 / 122 / 188（11/2はオープンカップで少ない）
- 最初の演目が10:30前後、最後が19:30前後
- `!!` の警告がゼロ、または全部目視で直した
- 会場ごとに30分以上の間隔で並んでいる

## 既知の弱点

- **WS系の会場（7・15・16・17・21列）**: 1セルに2名ぶんの番号が並ぶことがあり、片方の時刻が15分ずれる。2026年版では34件。自動では決められないので目視で直す
- **アイワポイント（4列）**: セルが1時間区切りで描かれていて開始時刻が機械的に決まらない。アプリ側にも「±15分のずれを見込んで現地の掲示を確認」と注記を出している
- **駿河区（29）・清水区（30・31）**: 徒歩圏外なので電車・バス扱い（静岡駅から25分／55分）。候補には出さず、自分で固定したときだけルートに乗る

## data.js の形

```js
window.DATA = {
  festival: { name, year, artistPage, schedulePdf, mapPdf },
  days:     [{ id: '11-01', label: '11/1 日', shows: [{ s: 会場番号, t: '11:00', e: '11:30', a: '17' }] }],
  stages:   [{ id, name, short, zone, area, pos, kind, note? }],   // zone: park|hakubutsu|gym|city|eki|suruga|shimizu
  artists:  { '17': { jp, en, country, genre, kid, why, img, desc } },
  premium:  { '11-01': [{ label, acts: ['15', '51'] }] },          // 有料ステージ（手入力）
  plans:    { '11-01': [{ id, title, sub, note, items: [{ t, s, a, note? } | { move }] }] },
  tips:     [[見出し, 本文]]
};
```
